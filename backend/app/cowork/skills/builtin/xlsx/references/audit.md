# XLSX 审计

默认只报告，不修改。先确定范围（选区 / 单 sheet / 全 workbook）；用户已给范围时不再询问。

## 必查项

| 严重度 | 检查 | 判据 |
|---|---|---|
| Critical | 显式公式错误 | `#REF!`、`#VALUE!`、`#DIV/0!`、`#NAME?`、不应出现的 `#N/A` |
| Critical | 被常量覆盖的公式 | 同一计算列/行中只有某格是硬编码值 |
| Critical | 范围少一行/多一行 | 聚合范围与真实数据块边界不一致 |
| Critical | 循环引用/断开的跨表引用 | 引用链无法收敛或目标不存在 |
| Critical | 跨 sheet 错位 | 必须打开源 sheet 核对真实表头、数据起止和重复区块，不能只看公式像不像 |
| Warning | 公式内业务硬编码 | 税率、价格、倍率等输入直接写在公式中而非假设单元格 |
| Warning | 公式模式中断 | 相邻公式的函数或相对引用形态不一致且无业务理由 |
| Warning | 单位/尺度混用 | 元/万元、0.85/85、币种、正负号口径混杂 |
| Warning | 隐藏行/sheet 的旧覆盖 | 隐藏区域含陈旧假设、手工覆盖或仍被引用的值 |
| Info | 可维护性 | 输入、计算、输出未区分；关键范围/公式缺说明 |

## 方法

1. 重新打开最终工作簿，枚举可见/隐藏 sheet、实际数据边界、公式格与名称/外部关系。
2. 按连续区域归纳公式模式；比较归一化相对引用，不把每个不同坐标都当差异。
3. 对跨 sheet 公式读取源区域，核对表头、起止行和单位；未读取源 sheet 就不能声称验证通过。
4. 有 LibreOffice 时重算并扫描结果；没有时只报告“静态公式检查”，不声称结果已核对。
5. 输出发现表：`Sheet | Cell/Range | Severity | Category | Issue | Suggested fix | Evidence`。

修复时先改最小范围，并重新审计完整作用域。不得把用户没有要求的模型假设改成自己的判断。
