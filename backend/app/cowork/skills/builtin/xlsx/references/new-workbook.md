# New workbook

原始数据先规范成稳定的行列结构。Summary sheet 放结论和关键指标，明细 sheet 放可追溯数据；
表头使用 header 样式并冻结。数字、布尔值保持原生类型，比例存小数；`WorkbookSpec v1` 不能从
JSON 传入原生 date/datetime，需要计算日期时应说明限制或改走已有工作簿的 sandbox 编辑。

写 Spec 前先画出每张 sheet 的坐标锚点：标题、表头、数据区、公式区、合计区和图表 anchor。区域
不得无意重叠；公式引用真实范围，图表引用稳定区域且 `data_range` 包含系列标题行。

所有长文本都必须允许换行，行高随内容增加；列宽按中文全角字符约 2 个英文字符计算并设置上限，
不能无限拉宽工作表。宽表使用横向打印和单页宽度缩放，但不把所有行强制压在一页高。至少检查
每个 sheet 是否有数据、公式是否含错误标记，以及文本是否可能在未换行的单元格里被截断。
