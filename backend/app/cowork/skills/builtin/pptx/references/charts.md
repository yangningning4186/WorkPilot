# Charts

图表必须服务一个明确结论。给出类别、系列、数值、单位与要强调的系列；不要用图表装饰页面。
类别超过 12 个时先聚合或拆页。数值来源应绑定 Evidence；图例、轴标题和颜色由 Renderer
按主题生成。

当前只支持 bar / column / line，不支持饼图、双轴、组合图或逐点自定义颜色。不能通过 Spec 指定
坐标轴标题或高亮单个数据点，所以关键单位与口径要写进可见页标题/系列名，关键结论写进标题，
不要在交付说明里承诺图内没有的标注。

- 时间序列用 line；分类对比用 column，类目名称较长时用 bar。
- categories 与每个 series.values 必须等长；缺失值不能用编造的 0 补齐，先说明口径或拆系列。
- 多系列只有在同一单位、同一比较口径下才放一起；不同单位不要伪装成可比。
- notes 写来源、统计区间、单位与必要的舍入规则，claim 绑定整页。
