# Images

## 先盘点能力与素材

先确认当前会话真实拥有的素材/工具，结论写入 DESIGN 的素材清单：

1. 用户材料或可信本地图：优先使用；
2. 当前工具面确实存在的图片生成能力：按统一风格词生成，并逐张查看后命名；
3. 图片生成能力不存在或失败：适合矢量表达时制作安全 SVG，否则改用原生结构；
4. 不得声称调用了未加载或不存在的图片生成器，不得用在线 URL 或占位符混过去。

每个素材条目记录：`source`、绝对本地路径、真实内容、宽高比、使用页、visual role、核对状态。
生成/复制后必须查看真实内容，确认语义、比例、清晰度和整套风格一致；不能按文件名猜图。

## Choose the visual form

- 数据比较与趋势：用 `chart`，不要把图表截图当图片。
- 时间阶段、象限：用 `timeline`、`matrix` 或 `two_column`，保持文字可编辑。
- 2–8 节点的流程、循环、层级、漏斗、金字塔：优先 `diagram`；特殊但无重叠的空间关系才用
  `canvas`，完整规则见 `diagrams-and-canvas.md`。
- 超过内置节点数、交叉连线复杂但确定性的示意图：可在 sandbox 生成本地 SVG，再用 `image_text` 嵌入。
- 照片与插画：只使用用户提供、已授权的本地素材，或当前环境中确实可用的图片生成工具产物。

不要声称调用了不存在的图片生成器。没有合适素材时，用图形、数据或留白，不伪造照片，也不
临时下载来源不明的素材。没有生成能力时，SVG 可以表达流程、关系、纹样、抽象概念以及能被可信
矢量化的风格物件；不能用几个圆和线冒充人物、校园活动、办公室、产品实景或摄影主视觉。

## Author SVG safely

SVG 应有明确 `viewBox`、有限画布、足够对比度和大字号文字。不要包含 `script`、事件属性、
`foreignObject`、外部 `href`、远程字体、base64 图片或 CSS `@import`。保留源 SVG 便于以后编辑；
Renderer 会在交付 PPTX 中嵌入兼容 PNG，以保证不同 Office 版本可打开。

## Fill the spec

只使用已授权的本地 SVG/PNG/JPEG/GIF。`title`/`section` 可用图片作 L1 主视觉，`image_text` 用于
图片/示意图与解释并列。设置 `image_path`、准确的 `image_alt`，需要展示来源或
解释时设置 `image_caption`。`image_fit="contain"` 保留完整内容，适合图表与示意图；
`image_fit="cover"` 允许居中裁切，适合照片。不要提供任意裁剪坐标。

生成后先调用 `preview_presentation` 看真实页图，检查：主体未被裁掉、文字可读、透明背景正确、
图片没有拉伸或像素化，caption 不与正文重叠；整套图片必须属于同一视觉类型。封面或半屏主视觉
不合格时先换素材/裁切，不用小装饰填补空白。
