# Typography

PPTX 同时写入 Latin 与 East Asian 字体信息。默认使用广泛可用的 Arial，并把中文映射为
Microsoft YaHei；如果用户指定字体，仍需确认目标设备安装了该字体，否则 PowerPoint 可能替换字形。

不要仅凭字体文件存在判断中文可用。内置预览会对实际文本检查缺失字形，并在宿主机没有中文字体时
使用应用自带的 CJK fallback。缺失字形、emoji 或特殊符号被拒绝时，替换为可用字符或经审查的图形，
不要接受方框、空白或乱码预览。

同一页最多使用标题与正文两种字重。中文粗体由真实粗体字体或受控描边合成；如果粗体导致拥挤，
应缩短文案或换布局，不通过减小到 16 pt 以下解决。
