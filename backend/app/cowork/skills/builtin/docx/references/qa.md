# DOCX QA

以最终保存的 DOCX 为验收对象：

1. **内容**：核对文体所需章节、受众与语气、数字/单位/日期/专名、未确认项、claim 来源；非模板
   文档不得有 TBD/XXX/示例文本，模板占位符必须显式且一致。
2. **结构**：重新打开，核对页型、页边距、标题层级、段落/列表/表格数量，以及 section/paragraph
   id 在 Spec 中唯一；确认没有因字段类型不匹配而消失的内容。
3. **版式对象**：第一节为 Heading 1、层级不跳级、列表为真实列表、表格有表头且网格固定、没有
   固定行高；大量明细不应硬塞进文档。
4. **图片与安全**：图片已嵌入、alt/caption 完整、比例正确，SVG 已转换为兼容 PNG；无外部关系、
   嵌入对象或远程资源。
5. **视觉**：渲染全部页面，检查孤行、标题悬空、表格截断、图片溢出、空白页、乱码和字体替换。
6. **修复循环**：修复后从最终 DOCX 重新运行全部检查，不只看修改过的页面。

预览失败或不可用时，只能报告结构验证结果，不能声称“版面已检查”。
