# D2 · 词法检索与 RRF 单变量对照（2026-08-14）

## 结论

在同一份 `core-dev` 与同一套 heading chunk 上, 只增加词法召回和 RRF 融合后,
span Recall@10 从 0.7396 提升到 0.8646（+12.50pt）, table 与 single-hop 均达到 1.0000。
此前唯一的 table 漏召回被回收到 Top 10, 证明该 badcase 是精确词面被整表语义稀释, 不是
Markdown/PDF 解析或索引覆盖问题。

multi-hop 的 Top-10 span recall 仍为 0.4583, 且 nDCG/MRR 下降。混合检索能把更多证据带进
Top 50, 但不能代替查询分解与 rerank。因此暂不以本实验宣称 multi-hop 已修复。

原始资料全程只读。逐样本问题、引用文字和文件名只保存在本地数据库及 Git 忽略目录; 本文只记录
聚合结果。

## 假设与单变量约束

- 假设: 专有名词、版本号、指标名与表格字段更依赖词面匹配; dense + 词法经 RRF 后可回收
  dense 排不到 Top 50 的证据。
- 唯一变量: `dense-only` → `dense + lexical + RRF(k=60)`。
- 保持不变: bge-m3 embedding、heading chunk、Top 10、诊断 Top 50、token budget=4000、
  gold overlap θ=0.5、无查询分解、无 rerank。
- 数据: 16 条可答人工题用于检索指标; 10 条不可答题用于分数诊断（4 human + 6 synthetic
  hard-negative）。

## 结果

| 指标 | dense-only | dense + lexical + RRF | Δ |
|---|---:|---:|---:|
| span Recall@10 | 0.7396 | 0.8646 | +0.1250 |
| budget span recall | 0.8021 | 0.9271 | +0.1250 |
| nDCG@10 | 0.5879 | 0.7201 | +0.1322 |
| MRR | 0.5885 | 0.7094 | +0.1208 |
| context precision | 0.0813 | 0.0938 | +0.0125 |
| mean latency | 175.5 ms | 255.3 ms | +79.7 ms |

| category | n | dense Recall@10 | RRF Recall@10 | 结论 |
|---|---:|---:|---:|---|
| single-hop | 7 | 0.8571 | 1.0000 | 回收 1 条精确词面证据 |
| multi-hop | 4 | 0.4583 | 0.4583 | Top 10 无增益, 仍需查询分解 |
| table | 5 | 0.8000 | 1.0000 | 唯一 table miss 被回收 |

gold span 状态从 `hit=16 / outside_top_k=3 / relevant_chunk_not_ranked=6` 变为
`hit=18 / outside_top_k=5 / relevant_chunk_not_ranked=2`。这说明 RRF 显著改善候选可得性, 但把
一部分证据从 Top 50 外推到 Top 10 外; 下一步的 Top-50 rerank 有明确空间。

multi-hop 的固定 token budget recall 从 0.4583 升至 0.7083, 但 Recall@10 不变且 nDCG 从
0.5206 降至 0.4773, 进一步说明候选进来了、最终排序仍不够好。

## table badcase 复核

- gold 表格完整序列化为 Markdown, 字符区间与 heading chunk 边界正确, 且相关 chunk 已向量化。
- dense Top 50 未命中, 但已召回同一文档的其他 chunk; 失败来自整张多行表格对短 query 的
  embedding 稀释。
- 新词法检索将目标 chunk 排第 1, RRF 后排第 10。
- 决策: 不重构 PDF 解析, 不修改原资料, 先由词法召回与 rerank 解决排序问题。

## 拒答观察

当前 0.35 dense 阈值仍放行全部 10 条不可答题。RRF 实验保留 dense 分数作为拒答诊断值,
因此分数分布没有变化; 这符合单变量约束，也再次说明拒答不能依赖单一 top score。
语义证据充分性闸门应在独立实验中评价, 不与本次检索增益混写。

## 决策

1. 采纳词法 + RRF; 后续组合拒答对照确认 hard-negative 拒答率不退化且误拒下降, 默认开关改为开启。
2. table badcase 结案为排序问题, 暂不重构 PDF/Markdown 解析。
3. multi-hop 继续做查询分解; Top-50 候选继续做 rerank。
4. 远端多查询与 rerank 正式跑批需先取得对具体 `core-dev` 批次及目标端点的明确外发授权。
