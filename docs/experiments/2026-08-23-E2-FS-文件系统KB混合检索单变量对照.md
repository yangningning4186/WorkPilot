# E2-FS · 文件系统 KB 混合检索单变量对照（2026-08-23）

## 结论

在 `rag-research` 的同一批 53 篇论文、同一份 26 条 synthetic 候选集上，只把检索引擎从
`dense` 改为 `hybrid（dense + BM25 + RRF）`：nDCG@10 点估计从 0.6216 升到 0.6608
（+3.92pt），span Recall@10 从 0.9773 升到 1.0000（+2.27pt）。两项 95% CI 都包含 0，
因此结论是**有正向信号但无显著差异**，不能宣称 hybrid 已被证明优于 dense。

hybrid 回收了 dense 在跨论文多跳题上的唯一漏召回，但单文档最大占比和上下文冗余显著上升；
另有一条法律 RAG 忠实性问题从 rank 1 降到 rank 3。决策是保留当前 active hybrid 和未激活的
`e2-dense` 对照版，不基于本轮 synthetic 结果继续改默认；先把候选集人工复核并扩充难例。

## 假设与单变量约束

- 假设：论文查询中的模型名、指标名、缩写和数值能从 BM25 获益，RRF 会提高 Top-10 排名质量，
  且不损害语义改写题的召回。
- 唯一变量：`RetrievalConfig.engine: dense → hybrid`。报告中同步变化的 `strategy`、
  `retrieval_score_source` 和 `kb_version_id` 都是该变量的派生记录，不是额外实验变量。
- 固定语料：53 个相同 `document_hashes`。
- 固定索引：两版均为 1,097 节点，`bge-m3:latest`、1024 维、revision
  `sha256-daec91ffb5dd0c27411bd71f29932917c49cf529a641d0168496c3a501e3062c`，
  `chunk_size=512`、`chunk_overlap=64`。
- 固定查询与 gold：`eval/suites/kb-rag-research-dev-v1.json`，suite SHA-256
  `ff41df7f59f4d259118882583e135ef1b0cd8dc391c9d76ac5d803088e1b3f3a`。
- 固定评测：Top-K=10、diagnostic-K=50、token budget=4000、θ=0.5、α=0.5，
  无 rerank、无 query rewrite、无生成模型。
- 固定实现：两份报告的 implementation fingerprint 均为
  `04aede5c7fa0d9144223216746d7bd6d9e0802951f6ab033a599c3098eb834f2`。
- 运行时 HEAD：`a453d6b14dfd2b34bc9d1a17bf28db1f3c81924c`；工作树为 dirty，
  所以复现应优先使用 suite/config/implementation/index 指纹，而不能只依赖 git SHA。

数据集包含 22 条可答题（9 exact identifier、11 semantic single-hop、2 multi-hop）和
4 条不可答题。它来自真实论文语料，但问题与标注尚未经过 owner 人工复核，因此只能用于工程
闭环和候选方向判断，不能升级为 human 产品基线或门禁快照。

## 结果

主指标预先固定为 nDCG@10；Recall 与固定 token budget Recall 是召回护栏。

| 指标 | dense | hybrid | Δ | 95% CI | 判定 |
|---|---:|---:|---:|:---:|---|
| span Recall@10 | 0.9773 | 1.0000 | +2.27pt | [0.00, +7.14]pt | 无显著差异 |
| budget span Recall | 0.9773 | 1.0000 | +2.27pt | [0.00, +7.14]pt | 无显著差异 |
| nDCG@10 | 0.6216 | 0.6608 | +3.92pt | [-3.08, +9.90]pt | 无显著差异 |
| MRR | 0.5122 | 0.5421 | +2.99pt | [-6.76, +11.49]pt | 无显著差异 |
| context precision | 0.1045 | 0.1091 | +0.45pt | [0.00, +1.43]pt | 无显著差异 |
| gold document Recall@10 | 0.9773 | 1.0000 | +2.27pt | [0.00, +7.14]pt | 无显著差异 |
| 单文档最大占比@10 ↓ | 0.6409 | 0.7136 | +7.27pt | [+0.87, +12.73]pt | **显著变差** |
| 上下文冗余率 ↓ | 0.0208 | 0.0279 | +0.72pt | [+0.29, +1.13]pt | **显著变差** |
| Top-10 上下文 token ↓ | 4,384 | 4,336 | -49 | [-116, +21] | 无显著差异 |

`refusal AUROC` 不做策略间结论：dense 使用 cosine similarity，hybrid 使用 RRF rank score，
两侧绝对分数不是同一尺度。本实验也没有配置拒答阈值。

### 分类别方向

| 类别 | n | dense nDCG@10 | hybrid nDCG@10 | Δ | 结论 |
|---|---:|---:|---:|---:|---|
| exact identifier | 9 | 0.6327 | 0.7194 | +8.66pt | 方向最强，但 CI 下界为 0，仍不显著 |
| semantic single-hop | 11 | 0.6273 | 0.6338 | +0.66pt | 基本持平，且有一条明显回退 |
| multi-hop | 2 | 0.5401 | 0.5456 | +0.55pt | n 太小；Recall 从 0.75 到 1.00 仅作线索 |

主指标逐题：8 条变好、1 条变差、13 条持平、4 条不可答题不适用。

## 归因

### 正向样本

- `rag-dev-004`（ROM / term importance）：gold 从 dense rank 2 升到 hybrid rank 1，
  nDCG +36.91pt；精确缩写和术语给了 BM25 明确信号。
- `rag-dev-016`（SciClaimSeekers / BM25 / multilingual E5 / RRF）：nDCG +24.41pt；
  查询中的方法名与正文高度重合。
- `rag-dev-015`（Active RAG / evidence budget）：nDCG +20.03pt。
- `rag-dev-005`（Ragas / ground-truth）：nDCG +16.67pt。
- `rag-dev-021`（跨两篇 query rewriting 论文）：dense 的 attribution 事实组落在 Top-10 外，
  hybrid 两个事实组均进入 Top-10，Recall 从 0.50 升到 1.00。

### 回退样本

- `rag-dev-008`（日本医疗诉讼 RAG）：dense 把 gold 页排第 1；hybrid 将药企 QA-RAG 的
  相近页面推到第 1，gold 降到第 3，nDCG -50pt。这里词法臂把 “RAG / context / domain”
  等共性词当成强信号，说明融合缺少文档级去重或多样性约束。

### 代价与噪声

单次配对中 hybrid 平均延迟比 dense 多 31.4ms，但这个数字不能当稳定因果估计：两次完全相同的
hybrid 复跑，所有质量指标与逐题排序差值都严格为 0，平均延迟却从 335.2ms 变为 253.7ms。
冷启动、索引缓存和顺序执行对延迟的影响大于本轮精确差值；本实验只记录 hybrid 多一路检索的
方向性成本，不据此做 SLA 决策。

## 决策与下一步

1. **维持当前 hybrid active，但不把本轮写成显著提升。** dense 版作为后续实验固定 control 保留。
2. owner 逐题复核这 26 条，补充至少 20 条真实问法，并把 multi-hop 扩到至少 10 条；审核前不更新
   retrieval baseline snapshot。
3. 下一轮仍只改一个变量：优先验证“每文档候选上限 / 文档级去重”能否降低单文档霸榜；
   不能同时再改 RRF、Top-K 或切分。
4. 拒答另开实验，使用策略无关的证据充分性信号；不得拿 dense cosine 阈值直接套 RRF 分数。
